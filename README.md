# W&S Engineering Store

Online store for W&S Engineering, reselling Kraft Tool Co. products. Customers place order requests; W&S orders from the supplier and invoices what arrives.

- **Spec:** `docs/SPEC.md`
- **Working with Claude Code:** `CLAUDE.md` (status, setup, rules, next task)
- **Brand wireframes:** open `docs/design/wireframes.html` in a browser

Stack: Next.js · Supabase · Resend · Vercel.

## What's here

The Supabase catalog is built and seeded (955 products, 4,493 variants, 1,300 photos). The Next.js app is the next step. See `CLAUDE.md` → Setup.
